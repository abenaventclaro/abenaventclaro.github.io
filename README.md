# Andreu Benavent-Claró — academic website

This is a static bilingual academic website (English + Catalan) prepared for GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create a GitHub account at github.com.
2. Choose a username you are happy to keep professionally.
3. Create a new **public** repository named exactly `YOURUSERNAME.github.io`.
4. Upload the contents of this folder to the repository root (not the outer folder itself).
5. In GitHub, open **Settings → Pages** and make sure the site is deployed from the `main` branch / root.
6. Your site will appear at `https://YOURUSERNAME.github.io`.

## Things to replace later
- Publication thumbnails / videos: replace the CSS placeholders with your own research figures or media.
- Paper PDFs: put legally shareable PDFs in `/papers/` and change publication title links from DOI URLs to `papers/filename.pdf` with the `download` attribute if you want direct downloads.
- On 15/09/2026, change “Incoming Postdoctoral Researcher” to “Postdoctoral Researcher” in Home, CV and Contact (and Catalan equivalents).
